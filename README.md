# 像素重力场 · 三关 Unity 原型

一款竖屏、马卡龙配色的轻量重力解谜游戏。依据《像素重力场》V1.0 策划案制作。

## 打开游戏

1. 用 **Unity Hub → Add project from disk** 选择此目录。
2. 推荐编辑器 **Unity 2022.3.62f1 LTS**，安装对应目标平台的 Build Support。
3. 打开 `Assets/Scenes/Garden.unity`，点击 Play。Game 视图推荐 420 × 900 或 9:19 竖屏。
4. 从首页开始第一关。点击下方的左、下、右按钮，或在棋盘内滑动；电脑也可用方向键 / A、S、D。
5. 通关解锁下一关；进度保存在本机 PlayerPrefs。第三关通关后可返回选关重玩。

无需账号、后端服务或在线美术资源。首次导入和构建仍需要本机已安装、已授权的 Unity 编辑器。

## 三关内容

| 关卡 | 内容 | 教学目标 |
| --- | --- | --- |
| 初见 · 一朵小花 | 粉色花朵，单色连通图案 | 自动运动、同色整片消除 |
| 午后 · 云间花园 | 蓝色花冠、粉色花瓣、绿色花台 | 从侧面入场、选择路径、多色与掉落 |
| 远行 · 环绕的岛 | 两侧花岛与中央花瓣 | 左右环绕、组合方向与连锁 |

运动间隔固定为 0.48 秒，每 11 步生成一颗星粒；玩家只能改变重力。底部粉线为危险线，左右边缘环绕不判失败。

## 已包含

- 14 × 19 棋盘；确定性生成；四邻接同色搜索；异色阻挡；左右环绕。
- 断开连通块的整体移动、掉落同色连锁、统一胜负判定。
- 手势 / 按钮 / 键盘输入、选关、解锁存档、重试、下一关、音乐开关。
- 原创兔子花园插画、纸张纹理、马卡龙色方格与圆角界面。
- 漂浮动画、移动补间、反向拖尾、目标掉落补间、整片闪光和碎片淡出。
- 原创 32 秒五声音阶循环配乐与三音消除音效，无外部音频采样。
- 随项目附带 Noto Sans CJK SC 字体及 SIL OFL 许可证。

未定案规则的原型取舍见 [Docs/设计与验证.md](Docs/设计与验证.md)。这是玩法原型，尚未完成移动端性能、商店打包、刘海屏安全区及完整无障碍适配。

## 验证

在安装 .NET 8 SDK 的机器执行：

```sh
python3 Tools/test_logic.py
```

测试直接编译游戏所用的 `GravityModel.cs`，不复制另一套玩法实现。覆盖环绕、连通、同色/异色接触、危险线、断块掉落、连锁和三关可解性。可解性搜索会输出每步方向序列到 `Tests/Results/`：0=下、1=左、2=右，每个字符持续一个逻辑步，第三关的解包含实际环绕。

本次云环境没有 Unity 编辑器，**没有运行 Unity Play Mode，也没有生成或验证 APK / EXE**。通过独立逻辑测试不能替代编辑器与真机验收。

## 资源与构建

`python3 Tools/generate_assets.py` 可重建原创 PNG 与 WAV，需要 Python Pillow；生成过程使用固定随机种子。字体为独立第三方开放许可资源，生成器不会下载或修改它。

在 Unity 的 File → Build Settings 中添加/确认 `Garden` 场景，切换 Android / iOS / Windows 等平台后构建。`Garden → Build Desktop` 为装有 Linux Build Support 的编辑器提供 Linux 构建入口。Unity 首次加载时会配置默认场景与竖屏分辨率。

核心代码：`Assets/Scripts/GravityModel.cs`（独立逻辑）、`Assets/Scripts/PixelGarden.cs`（显示、输入与音频）；美术和音乐位于 `Assets/Resources/`。
