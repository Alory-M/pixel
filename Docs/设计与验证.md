# 原型规则与验证边界

## 对策划案未定规则的取舍

- 向上重力不开放；不提供暂停与速度控制。
- 同色命中后运动星粒消耗，四方向连通的目标色块一起消除。
- 异色接触与运动星粒之间的接触会阻挡；玩家改变方向后继续运动。
- 每次消除后按四方向搜索剩余目标的连通块。最大的连通块暂作锚定主体，其余连通块作为刚体沿当前重力结算。这是原型选定规则，不是策划案已定案的“底部支撑”规则。
- 断块接触同色目标时，匹配的同色连通区继续消除，递归结算；异色接触会停止移动。
- 同一时刻的星粒按生成顺序的逆序结算，避免重复移除目标；目标为空优先判成功。
- 第 19 行的上边沿为粉色危险线。运动星粒进入该行失败，掉落目标停在危险线上一行。
- 左右环绕保持所在行、颜色与速度。水平方向孤立断块的单轮结算有步数上限，避免无支撑的无限循环；此处可在后续关卡系统中扩展为持续运动刚体。
- 初始运动星粒于第一个逻辑步生成，此后每 11 步生成；颜色按当前剩余色序列轮转，不生成已完全清空的颜色。
- 不引入时间限制、体力、付费或广告系统。

## 关卡可复现性

三关图案、出生列与颜色规则在 GravityModel 内集中定义，均非随机。Tests/LogicTests.cs 的束搜索直接调用真实模型，证明至少存在一条获胜的方向序列；不代表人工试玩的难度与节奏已经调优。第三关的搜索要求最终成功且至少发生一次环绕。

## 当前验证范围

独立 C# 模型测试可以验证规则和三关可解性。尚待在 Unity 2022.3 编辑器中核验资源导入、场景加载、中文字体、声音、触摸、宽高比和实际构建。不能将本工程称为已验收的手机安装包。

建议编辑器验收：

1. 从首页进入第一关，完成后确认第二关解锁，重开程序确认存档。
2. 分别测试按钮、滑动与键盘；方向变化不改变步进频率。
3. 让星粒从左/右边缘穿过，检查同一行重新出现、拖尾方向正确。
4. 比较同色与异色命中；观察整片闪光、掉落与连锁音效。
5. 将星粒引到底部，确认失败后重试恢复原图案。
6. 完成第三关，确认最终文案和返回选关；测试静音。
7. Android 真机验证触摸、声音恢复、竖屏、刘海屏与不同分辨率。

## 原创素材

Tools/generate_assets.py 使用 Pillow 绘制花园、兔子、云、花朵、纸张和圆角蒙版，并通过正弦波与包络合成原创背景音乐和音效。运行时动画由 PixelGarden.cs 生成。未使用外部角色、音乐采样或商业素材。中文字体为 Noto 项目授权资源，许可证随字体附带。
